# أورفت بلس — نسخة أولية قابلة للتشغيل

## التشغيل على الكمبيوتر
1. ثبّت Node.js إصدار 18 أو أحدث.
2. فك ضغط الملف.
3. افتح الطرفية داخل مجلد المشروع ونفّذ:
   `npm install`
4. انسخ `.env.example` إلى ملف باسم `.env`.
5. ضع مفتاح OpenRouter الجديد داخل `.env` في `OPENROUTER_API_KEY`، ولا ترسله بالمحادثة ولا تضعه في `public`.
6. شغّل: `npm start`
7. افتح Chrome على `http://localhost:3000`.

## التشغيل على أندرويد
يمكن تشغيله عبر بيئة تدعم Node.js مثل Termux: ثبّت Node.js، فك الضغط، نفّذ `npm install` ثم `npm start`، وافتح `http://127.0.0.1:3000` في Chrome.

## ملاحظات
- الواجهة والسجل المحلي والحاسبات تعمل دون ربط AI.
- تحليل الصور والنص والمدرب الذكي يحتاجون مفتاحاً جديداً صالحاً ونموذجاً يدعم الصور عند تحليل الصور.
- النموذج الافتراضي `openai/gpt-4o-mini` قد لا يكون مجانياً؛ الأسعار والتوفر حسب OpenRouter. يمكنك تغيير `OPENROUTER_MODEL` في `.env` إلى نموذج متاح يدعم الصور.
- البيانات محفوظة محلياً في المتصفح (localStorage)، وليست حساباً سحابياً أو مزامنة بين الأجهزة.
- تقديرات الطعام وحرق السعرات تقريبية. لا تعتمد التطبيق للتشخيص أو لخطة تنشيف، وخصوصاً لمن هم دون 18 سنة.
